# 🤖🪜 Simulador dels Esglaons i Fibonacci (PCMAT)

Aplicació web interactiva dissenyada per a l'alumnat de primària per explorar la **Successió de Fibonacci** i el **pensament computacional** a través de la resolució del problema dels camins a l'escala (salts de +1 🦶 i +2 🪜).

## 🌟 Característiques principals

- **🏃 Simulador d'Escales (N=1..6):** Exploració manipulativa i visual amb diferenciació de colors per tipus de salt i opció d'acumular traces de recorregut.
- **🪜 Escales Llargues (N=7..12):** Mode de simulació automàtica amb selecció de velocitat (🐢, 🏃, ⚡) i patró de Fibonacci.
- **📊 Taules de Registre:** Organització dinàmica dels camins trobats i comprovació de la taula de doble entrada.
- **🏆 Conclusió Matemàtica Visual:** Deducció de la fórmula $Camins(N) = Camins(N-1) + Camins(N-2)$ adaptada a Lectura Fàcil.
- **♿ Disseny Accessible (NESE):** Interfície intuïtiva, alta contrastabilitat visual i executable en un únic fitxer autònom (`Single-File HTML`).
